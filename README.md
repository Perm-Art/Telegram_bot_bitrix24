# Bitrix24 API Assistant Bot

Интеллектуальный чат-бот для Telegram, который помогает разработчикам работать с API Bitrix24. Бот использует Yandex GPT 5.1 для генерации ответов на вопросы о методах, параметрах и примерах использования REST API Bitrix24.

## 🚀 Возможности

- **Интеллектуальные ответы**: Использование Yandex GPT 5.1 для понимания и ответа на вопросы
- **База знаний**: Хранение и поиск информации из документации Bitrix24
- **История диалогов**: Сохранение контекста разговора
- **PostgreSQL**: Надежное хранение данных
- **Парсер документации**: Автоматическое обновление базы знаний

## 📋 Требования

- Python 3.9+
- PostgreSQL 12+
- Telegram Bot Token
- Yandex Cloud аккаунт с активированным Yandex GPT API
